# TOKI SATSUEI media library

Upload folders are organised by photography type. Create one folder per shoot inside the relevant category; the folder name becomes the album title.

## Categories
- `cosplay/` — cosplay and character photography
- `portraits/` — individual portraits
- `duo-groups/` — duo, pair, and group sessions
- `events/` — conventions, gatherings, and event coverage
- `casual-outdoor/` — casual and outdoor sessions
- `behind-the-scenes/` — setup, preparation, and behind-the-camera moments

## Recommended upload pattern
`<category>/<album-name>/<your-photo>.jpg`

Example: `cosplay/november-convention-2026/legion-001.webp`

Supported formats: JPG, JPEG, PNG, WEBP, AVIF, GIF, MP4, and WEBM. The archive scans album folders automatically during each GitHub Pages build. No manual manifest editing is required.

Files uploaded directly inside a category folder appear in an album named **Latest uploads**. Keep filenames readable. Use web-ready exports and do not put private client material or camera RAW files in this public repository.
